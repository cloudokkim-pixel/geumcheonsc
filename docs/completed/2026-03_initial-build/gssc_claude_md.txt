## 절대 원칙 — 반드시 먼저 읽을 것

1. **모바일 퍼스트.** 모든 컴포넌트는 375px(모바일) 기준으로 먼저 구현하고 데스크탑으로 확장한다.
2. **`max-width` 미디어 쿼리 사용 금지.** `min-width` 기반 작성만 허용.
3. **카피 임의 수정 금지.** 모든 텍스트는 카피라이팅 파일(GCSC_copy_0*.html)에서 가져온다.
4. **사업자등록번호 `123-12-12345` 는 임시값.** 배포 전 실제 번호로 교체 필수.

## 컴포넌트 구현 핵심 규칙

### GNB
- 모바일: 높이 56px, 햄버거 메뉴 (44×44px 터치 타겟), 풀스크린 오버레이
- 데스크탑 (768px+): 높이 64px, 수평 메뉴 + CTA 버튼
- `padding-top: env(safe-area-inset-top)` 필수 (iPhone 노치 대응)

### 히어로 섹션
- 높이: `100svh` (fallback: `100vh`)
- 배경 영상 시: `muted playsinline autoplay` 3개 속성 필수
- CTA 버튼: 모바일 `width: 100%`, 높이 52px

### 카드 그리드
```css
grid-template-columns: 1fr;                          /* 모바일 */
@media (min-width: 768px)  { repeat(2, 1fr); }      /* 태블릿 */
@media (min-width: 1024px) { repeat(3, 1fr); }      /* 데스크탑 */
gap: 12px → 24px;
```

### 커리어 로드맵 인포그래픽
- 데스크탑: `grid-template-columns: 1fr 80px 1fr` (중앙 타임라인, 좌/우 트랙)
- 모바일: `grid-template-columns: 56px 1fr` (세로 단일 컬럼)
- 선수 트랙 `#cc2222` / 진학 트랙 `#c49550`
- 참조: `GCSC_roadmap_infographic.html`

### 선수모집 신청 폼
- 필드 높이: 48px
- **폰트 크기: 16px 이상 필수** (iOS 자동 zoom 방지 — 절대 줄이지 말 것)
- 레이블: placeholder 대신 필드 위 항상 표시
- Route Handler: `src/app/api/apply/route.ts`

### 경기 일정
- 모바일: 테이블 → 카드 리스트 전환
- 데스크탑: 기본 테이블

### 푸터
- 전화번호: `<a href="tel:01041780207">` 필수
- 주소: 카카오맵 딥링크 연결

## CMS — Notion 연동

```typescript
// src/lib/cms.ts
import { Client } from '@notionhq/client'
const notion = new Client({ auth: process.env.NOTION_API_KEY })

export async function getSchedule() {
  const res = await notion.databases.query({
    database_id: process.env.NOTION_DB_SCHEDULE!,
    sorts: [{ property: '날짜', direction: 'descending' }],
  })
  return res.results
}

export async function getGallery() {
  const res = await notion.databases.query({
    database_id: process.env.NOTION_DB_GALLERY!,
    sorts: [{ property: '날짜', direction: 'descending' }],
  })
  return res.results
}
```

```typescript
// 페이지에서 사용
export const revalidate = 3600 // ISR 1시간 캐시
```
