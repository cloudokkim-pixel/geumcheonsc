Google Search Console사이트 등록 + sitemap.xml 제출. 검색 노출 현황 무료로 확인 가능.search.google.com/search-console (무료)높음

비용 0원 SEO 순서

① 메타 태그 + OG 태그 + alt 텍스트 삽입 (개발 단계) → ② Google Search Console + 네이버 서치어드바이저 등록 (런칭 직후) → ③ Google Analytics 설치 → ④ 네이버 블로그 + 지역 카페 운영 (런칭 후 꾸준히). 돈 한 푼 안 쓰고 이것만 해도 지역 검색 상위 노출 충분히 가능.
