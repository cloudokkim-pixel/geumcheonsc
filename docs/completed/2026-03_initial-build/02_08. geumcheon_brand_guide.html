브랜드 아이덴티티

약자 G.C.S.C (Geumcheon Sport Social Coop). 영문명은 GEUMCHEON으로 통일.

02 — Color System
컬러 시스템

3색 시스템으로 각 컬러에 명확한 역할을 부여합니다. 레드와 세피아를 같은 공간에 함께 사용하지 않습니다.

로고 골드에서 채도를 낮춘 색. 노랑 느낌 없이 중후함. 클럽의 역사와 정체성을 담는 곳에만 사용.

헤드라인과 핵심 정보. 다크 배경에서 "빛"의 역할. 충분히 밝아야 어둡게 느껴지지 않음.

#6E6E73
다크그레이 — 보조 정보
날짜, 카테고리, 라벨 등 보조 정보. 읽힐 필요는 있지만 주목받지 않아야 하는 텍스트.
날짜·카테고리 푸터 텍스트 stat 서브텍스트

컬러 사용 핵심 규칙

레드와 세피아를 같은 섹션에 함께 사용하지 않는다 — 한 섹션에 하나만
레드는 클릭을 유도하는 버튼과 섹션 시작 라벨에만 — 장식용 사용 금지
세피아는 창단 연도, 배지, Club Promise에만 — "역사와 약속"을 담는 곳
배경은 #000 단일 블랙 유지 — 섹션마다 배경색 변경 금지, border-top으로만 구분
로고 골드(#f0a800)와 사이트 세피아(#c49550)는 다른 색 — 의도적 구분, 맞출 필요 없음

05 — Logo Usage
로고 사용 규칙

로고는 클럽 아이덴티티의 핵심입니다. 일관된 사용이 브랜드 신뢰도를 높입니다.

올바른 사용

✓검정 배경 위에 원본 그대로 사용
✓네비게이션: 38x38px 이상
✓푸터: 32px, opacity 0.7로 절제
✓로고 주변 최소 여백: 로고 크기의 25% 이상

금지 사항

✗색상 변경 또는 CSS filter 적용
✗로고 위에 텍스트 겹치기
✗비율 변경 (가로/세로 독립 리사이즈)
✗저해상도 PNG 확대 사용 (400px 이하 원본)

06 — Dev Guide
개발 적용 가이드

VS Code Claude에 전달할 핵심 CSS 변수와 설정값입니다. 이 값들을 기준으로 전체 사이트를 구현합니다.

/* ===== G.C.S.C 브랜드 가이드 v1.0 ===== */ /* 폰트 임포트 */ @import url('https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.css'); /* Google Fonts: Barlow Condensed 700, 800 */ /* 기본 설정 */ body { background: #000; font-family: 'Pretendard', 'Apple SD Gothic Neo', sans-serif; -webkit-font-smoothing: antialiased; word-break: keep-all; /* 필수 */ } /* 컬러 시스템 */ --red: #cc2222; /* 행동 유도 */ --sepia: #c49550; /* 역사·정체성 */ --white: #f5f5f7; /* 헤드라인·핵심 정보 */ --body: #c0c0c5; /* 본문 텍스트 */ --muted: #6e6e73; /* 보조 정보 */ --card: #1c1c1e; /* 카드 배경 */ --border: #1e1e1e; /* 구분선 */ /* 헤드라인 (Barlow Condensed) */ font-family: 'Barlow Condensed', sans-serif; font-weight: 800; text-transform: uppercase; letter-spacing: 0.01em; /* 섹션 타이틀 크기 */ font-size: clamp(40px, 5vw, 60px); /* 본문 (Pretendard) */ font-size: clamp(15px, 1.8vw, 17px); line-height: 1.9; color: #c0c0c5; /* 카드 */ background: #1c1c1e; border-radius: 4px; /* 각진 느낌 유지 */ /* 섹션 구분 — 배경색 변경 금지 */ border-top: 1px solid #1e1e1e; padding: 96px 48px;
