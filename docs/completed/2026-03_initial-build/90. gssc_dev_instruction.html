컬러 사용 규칙 — 엄격히 준수
Brand Red (#cc2222): CTA 버튼, 강조 텍스트, 행동 유도 요소 전용.
Brand Gold (#c49550): 역사·정체성·실적 관련 섹션 전용.
금지: Red와 Gold를 동일 섹션에 함께 사용하지 않는다. 둘 중 하나만 선택.
타이포그래피
영문 헤드라인 / 섹션 타이틀: Barlow Condensed 800 · uppercase
한글 본문 / UI 텍스트: Pretendard 400·600·700
Eyebrow 레이블: Barlow Condensed 700 · uppercase · letter-spacing 0.15em

사이즈 스케일 (모바일 → 데스크탑):
히어로 헤드라인: clamp(32px, 7vw, 54px)
섹션 타이틀: clamp(22px, 4vw, 36px)
카드 타이틀: 17px → 20px
본문: 15px → 16px · line-height 1.7
캡션: 12px → 13px

06 — Copywriting
카피라이팅 삽입 규칙
카피라이팅 파일 11개가 완성되어 있습니다. 각 페이지 구현 시 해당 카피 파일을 열고 섹션별로 텍스트를 복사하여 마크업에 삽입합니다. 절대 카피를 임의로 수정하거나 생략하지 마세요.
카피 파일 우선: 각 페이지 마크업의 모든 텍스트는 해당 카피 파일에서 가져온다. Claude Code 임의 생성 텍스트 금지.
【확인 필요】 처리: 카피 파일 내 【확인 필요】 표시 항목은 플레이스홀더 텍스트로 마크업에 삽입. 실제 데이터 입력은 리더옥님 확인 후 진행.
섹션 구조 일치: 카피 파일의 섹션 번호(S1, S2…)와 페이지 섹션 순서를 1:1 대응. 섹션 순서 임의 변경 금지.
Eyebrow / 헤드라인 분리: 카피 파일의 eyebrow, 헤드라인, 서브카피, 본문을 각각 별도 태그로 마크업. 하나의 p 태그에 몰아넣지 말 것.
모바일 주의사항: 카피 파일 각 섹션 하단 파란 박스의 모바일 주의사항을 반드시 읽고 구현에 반영할 것.
확인 필요 항목 — 리더옥님 제공 대기 중

08 — CMS
CMS 구현
경기일정·갤러리·훈련공지는 클럽 대표가 직접 업데이트 가능한 관리자 구조가 필요합니다. 복잡한 CMS 구축 대신 Notion Database + Next.js 연동을 권장합니다. 비용 0원, 모바일 입력 최적.
권장 Notion Database 방식
장점: 리더옥님이 모바일 Notion 앱에서 직접 데이터 추가·수정 가능. 개발 비용 최소.

설정:
1. Notion에 경기일정 DB, 갤러리 DB 생성
2. Notion API 키 발급
3. Next.js에서 @notionhq/client로 fetch
4. ISR (revalidate: 3600) 적용 — 1시간 캐시
5. 환경변수 NOTION_API_KEY, NOTION_DB_ID_* Vercel에 등록
대안 정적 JSON 파일 방식
장점: 외부 의존성 없음. 완전 정적.
단점: 데이터 수정 시 GitHub 커밋 필요. 비개발자에게 불편.

Notion 연동 코드 (lib/cms.ts)
import { Client } from '@notionhq/client'

const notion = new Client({ auth: process.env.NOTION_API_KEY })

export async function getSchedule() {
  const res = await notion.databases.query({
    database_id: process.env.NOTION_DB_SCHEDULE!,
    sorts: [{ property: '날짜', direction: 'descending' }],
  })
  return res.results
}

export async function getGallery() {
  const res = await notion.databases.query({
    database_id: process.env.NOTION_DB_GALLERY!,
    sorts: [{ property: '날짜', direction: 'descending' }],
  })
  return res.results
}
