현재
"참가 신청" 제목 하나. 폼으로 바로 진입. 왜 신청해야 하는지 설득 전무.
변경 헤드라인
"선수의 길,
지금 시작하세요"
서브: 초등부 · 중등부 · 고등부 · 성인부 전 연령 모집 중
변경 이유
모집 페이지는 전환율이 핵심. 신청 폼으로 바로 가기 전에 "왜 G.C.S.C인가"를 한 번 더 상기시켜야 이탈률이 줄어듦.

Age Group Requirements
연령별 모집 요강 4개 탭
신규

4개 탭
초등부 U6~U12 / 중등부 U13~U15 / 고등부 U16~U18 / 성인부 K4 지망
각 탭 모집 요강
모집 대상 / 훈련 시간 / 훈련 장소 / 월 회비 / 선발 방식 / 문의 연락처
추가 이유
현재 중등/고등만 있고 초등·성인 없음. 연령별로 모집 조건이 다르기 때문에 탭으로 분리해야 원하는 정보를 빠르게 찾을 수 있음.

4단계 프로세스
01 신청 — 온라인 폼 또는 전화 문의
02 상담 — 대표 1:1 상담 (목표/현재 수준 파악)
03 테스트 — 기초 기술 테스트 참관
04 입단 — 입단 확정 및 훈련 시작
목적
"신청하면 어떻게 되나요?"라는 학부모 불안감 해소. 절차가 명확할수록 신청률 상승.

개선

현재 폼 필드
이름 / 학교명 / 학년 / 연락처 / 기타 — 5개. 연령 구분 없음.
변경 후 필드
이름 / 연락처 / 지원 연령부(드롭다운) / 현재 학교 및 학년 / 훈련 경험 유무 / 문의 내용(textarea)
→ 6개 필드로 정보 질 향상
제출 버튼
"입단 신청하기" — 레드 전체 너비 버튼
전화 문의 병기
폼 하단에 010-4178-0207 전화번호 노출. 폼이 불편한 사람을 위한 대안 제공.
개선 이유
현재 폼은 "학교명"을 묻지만 연령부를 안 물어봄. 담당자가 어느 연령 문의인지 구분이 안 됨. 지원 연령부 드롭다운 추가가 운영 효율에 핵심.
