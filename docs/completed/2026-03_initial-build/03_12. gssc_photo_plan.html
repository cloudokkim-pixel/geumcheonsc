02 — Page Analysis
페이지별 사진 필요 분석
보유 사진으로 커버 가능한 페이지와 신규 촬영이 필요한 페이지를 분리합니다.
페이지 필요한 사진 유형 보유 충당 가능 여부 비고
홈 (히어로) 야간 훈련 사진 — 어둡고 강렬한 현장감 보유로 가능 어두운 톤, 선수 동작 있는 사진 1장 선별
홈 (갤러리 미리보기) 훈련 현장 3장 — 다양한 장면 보유로 가능 밝기·구도 다른 3장 선별
클럽소개 (히어로) 팀 전체 단체 사진 또는 훈련 전경 일부 가능 단체 사진 없으면 훈련 전경으로 대체 가능
클럽소개 (코치 프로필) 코치 개인 프로필 사진 — 정면, 흰 배경 또는 구장 배경 신규 촬영 필수 천경필 대표 포함 코치진 전원. 이번 주 내 촬영.
클럽소개 (활동 사진) 훈련/경기 현장 3장 보유로 가능 홈과 중복 안 되게 별도 선별
육성시스템 (히어로) 코칭 장면 — 코치가 선수에게 지도하는 모습 일부 가능 지도 장면 없으면 이번 주 훈련 중 추가 촬영 권장
선수모집 (히어로) 선수 단독 or 소그룹 — 집중하는 모습 보유로 가능 어린 연령부터 고등부까지 다양하면 좋음
갤러리 훈련/경기/행사 사진 전체 보유로 가능 전체 업로드. 연령 태그 필수.
커리어 로드맵 (히어로) 선수가 멀리 바라보는 장면 — 미래 지향적 구도 일부 가능 없으면 인포그래픽 배경으로 대체 가능
진학현황 (히어로) 시상식 또는 졸업/입단 기념 사진 일부 가능 없으면 경기 사진으로 대체 가능
후원 (히어로) 어린 선수들 밝은 장면 — 훈련 즐거운 모습 보유로 가능 ESG 정서와 맞는 밝고 따뜻한 사진
경기일정 (히어로) 경기 중 액션 사진 보유로 가능 드리블/슛 등 역동적인 장면
핵심 결론

이번 주 촬영은 딱 두 가지만 집중하면 됩니다. ① 코치진 프로필 사진 (필수, 대체 불가) ② 코치가 선수를 지도하는 장면 (육성시스템 히어로 — 없으면 약점 생김). 나머지는 보유 사진 선별로 전부 커버 됩니다.

03 — Shoot List
이번 주 신규 촬영 목록
코치 프로필
최우선
천경필 대표 — 정면 촬영. 표정 자연스럽게. 클럽 유니폼 착용.
코치진 전원 — 동일한 조건으로 통일감 있게.
배경 2가지 옵션: ① 구장 배경 (자연스러움) ② 단색 배경 (정갈함). 둘 다 찍어두고 선택.
1인당 최소 3~5컷 이상 촬영. 선택지 확보.
사용 페이지: 클럽소개 · 육성시스템 · 선수모집 · 홈페이지 신뢰도 전반
지도 장면
높음
코치가 선수에게 설명하는 장면 — 사이드라인에서 전술 지도하는 모습.
코치와 선수가 함께 있는 장면 — 볼 앞에서 개인 지도.
팀 미팅 장면 — 코치가 선수들 앞에서 이야기하는 모습.
사용 페이지: 육성시스템 히어로. 현재 없으면 페이지 인상이 약해짐.
연령별 훈련 장면
높음
초등부 훈련 장면 — 보유 사진에 없을 가능성 높음. 어린 선수들 볼 다루는 모습.
연령 혼재 장면 — 초등/중등/고등 같은 프레임에 있으면 "전 연령 클럽"임을 시각적으로 증명.
사용 페이지: 홈 히어로, 선수모집, 파이프라인 섹션
야간 훈련 장면
높음
야간 구장 조명 아래 훈련 장면 — 홈 히어로 핵심. 어둡고 강렬한 분위기.
보유 사진에 야간 훈련이 있다면 스킵 가능. 없으면 이번 주 야간 훈련에서 반드시 촬영.
사용 페이지: 홈 히어로 배경. 브랜드 첫인상 결정하는 사진.

05 — Photo Curation
보유 사진 선별 기준
30장 이상 보유 사진에서 페이지별로 최적 사진을 배분합니다. 모든 사진을 쓸 필요는 없습니다.
쓸 수 있는 사진
밝기너무 어둡지 않은 것
초점선수 얼굴/몸이 선명한 것
배경구장 배경이 보이는 것
구도훈련/경기 중 자연스러운 것
분위기진지하거나 역동적인 것
버려야 할 사진
품질흔들리거나 초점 안 맞은 것
배경잡동사니/차량/건물 있는 것
표정어색하거나 찡그린 것
구도선수가 너무 작게 나온 것
기타개인 정보 노출 우려 있는 것
페이지별 배분 원칙

홈 히어로 1장 → 클럽소개 3장 → 육성시스템 히어로 1장 → 선수모집 히어로 1장 → 후원 히어로 1장 → 경기일정 히어로 1장 → 갤러리 전체 업로드. 같은 사진이 여러 페이지에 중복 노출되지 않도록 배분합니다.

06 — This Week Schedule
이번 주 촬영 타임라인
모든 신규 촬영은 이번 주 훈련 시간에 병행 가능합니다. 별도 스튜디오 예약 불필요.
Day 1~2
보유 사진 전체 검토 + 페이지별 배분
30장 이상 사진 중 사용 가능한 것 선별. 페이지별 배분 완료. 신규 촬영 필요 항목 최종 확인.
Day 2~3
코치진 프로필 사진 촬영 (최우선)
훈련 시작 전 30분 활용. 천경필 대표 + 코치진 전원. 1인당 5컷 이상. 구장 배경 + 단색 배경 각 촬영.
Day 3~4
지도 장면 + 연령별 훈련 장면 촬영
훈련 중 자연스럽게 촬영. 코치-선수 지도 장면, 초등부 훈련 장면, 야간 훈련 장면(없는 경우).
Day 4~5
사진 정리 + 카피라이팅 작업 병행 시작
신규 촬영 사진 선별 완료. 페이지별 배분 확정. 이후 카피라이팅 작업(태스크 13) 바로 진입.
