wireframe S3
카드 제목 작성 규칙
형식: [연령부] YYYY년 MM월 N주차 훈련/경기

예시:
· [금천U-15] 2026년 03월 3주차 훈련
· [금천초등부] 2026년 04월 주말리그 경기
· [금천고등부] 2025년 12월 종무식 행사
· [금천U-15] 2026년 03월 전국대회 참가
Note
제목 형식 통일이 필터링 정확도와 직결됨. 연령 태그([금천U-15] 등)는 반드시 앞에. 형식 안 지키면 연령별 필터가 제대로 동작 안 함.
카테고리 태그 4종 — 색상 + 용도
훈련
정규 훈련, 개인 레슨, 기술 훈련 등 일상 훈련 전체. 업로드 빈도 가장 높음.
경기
주말리그, 대회, 친선 경기 등 실전 경기 전체. 학부모가 가장 찾는 카테고리.
행사
시즌 개막식, 종무식, 시상식, 단체 활동 등 특별 행사.
기타
위 세 카테고리에 해당하지 않는 사진. 클럽 소식, 환경 사진 등.
모바일 퍼스트
모바일에서 갤러리 그리드는 2열로. 데스크탑 3열 → 태블릿 2열 → 모바일 2열(또는 1열). 각 카드 aspect-ratio: 4/3 유지. 카드 오버레이 텍스트는 모바일에서도 반드시 읽혀야 함 — 폰트 최소 11px, 오버레이 opacity 충분히.
빈 상태 메시지 (사진 없을 때)
아직 등록된 사진이 없습니다.
경기나 훈련 후 사진을 업로드하면 이곳에 표시됩니다.
Note
필터 조합 결과가 없을 때 표시. "아직 공개된 갤러리가 없습니다" 같은 기존 문구보다 운영 의도를 담은 문구로 교체.
운영 원칙
갤러리 운영 기준
개발 완료 후 클럽 대표가 직접 운영
운영 가이드
업로드 운영 원칙
업로드 주기: 경기·훈련 후 48시간 이내. 늦을수록 학부모 재방문 동기 사라짐.
빈 갤러리 노출 금지: 사진 없으면 "준비 중" 메시지 대신 기존 보유 사진 유지. 빈 페이지는 클럽이 운영 안 되는 것처럼 보임.
제목 형식 통일: [연령부] YYYY년 MM월 N주차 훈련/경기. 이 형식 안 지키면 필터가 안 됨.
연령 태그 필수: 업로드 시 연령부 선택 빠짐없이. 학부모가 "우리 아이 연령" 필터로 찾음.
개인정보 주의: 미성년자 얼굴이 크게 나오는 사진은 학부모 동의 확인 후 업로드.
