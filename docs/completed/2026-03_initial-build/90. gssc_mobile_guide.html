01 — Breakpoints
브레이크포인트 정의
이름 범위 설명 우선순위
mobile-sm 320px ~ 374px 소형 스마트폰 (iPhone SE 등) 기준점
mobile 375px ~ 767px 표준 스마트폰 — 주요 타겟 PRIMARY
tablet 768px ~ 1023px 태블릿 / 대형 폰 가로 보조
desktop 1024px ~ 1279px 노트북 / 소형 모니터 확장
desktop-lg 1280px+ 와이드 모니터 확장 
/* CSS 변수로 관리 — 전체 프로젝트 동일 사용 */
:root {
  --bp-mobile-sm: 320px;
  --bp-tablet:    768px;
  --bp-desktop:   1024px;
  --bp-desktop-lg:1280px;
}

/* 작성 순서: 모바일 기본값 → 태블릿 → 데스크탑 */
.component {
  padding: 16px;                           /* 모바일 기본 */
}
@media (min-width: 768px)  { .component { padding: 24px; } }
@media (min-width: 1024px) { .component { padding: 40px; } }
금지 사항
max-width 미디어 쿼리 사용 금지. 데스크탑 우선으로 작성 후 max-width로 줄이는 방식은 이 프로젝트에서 허용하지 않습니다. 모든 스타일은 모바일 기본값 → min-width 확장 순으로 작성.
02 — Touch & Interaction
터치 영역 & 인터랙션 규칙
44px
최소 터치 타겟
모든 탭 가능 요소의 최소 높이·너비. 버튼, 링크, 아이콘 포함. Apple HIG / Material 기준.
8px
타겟 간 최소 간격
인접 터치 영역 사이 최소 여백. 오터치 방지.
16px
좌우 엣지 마진
화면 양 끝 기본 여백. 손가락이 베젤을 가리는 영역 회피.
300ms
딜레이 제거
touch-action: manipulation 적용 필수. 탭 지연 300ms 제거.
/* 전역 터치 최적화 */
* {
  -webkit-tap-highlight-color: transparent;
}

a, button, [role="button"], input, select, textarea {
  touch-action: manipulation;
  min-height: 44px;
  min-width: 44px;
}

/* 아이콘만 있는 버튼 — 시각 크기와 터치 타겟 분리 */
.icon-btn {
  display: flex;
  align-items: center;
  justify-content: center;
  min-height: 44px;
  min-width: 44px;
  padding: 10px;
}
스크롤 & 제스처
모멘텀 스크롤: iOS에서 -webkit-overflow-scrolling: touch + overflow-y: scroll 적용.
스와이프 갤러리: CSS scroll-snap 사용. JS 라이브러리 최소화.
네비게이션 바: 모바일에서 하단 고정 또는 상단 sticky. 스크롤 시 숨김 처리 금지 (콘텐츠 접근성 저하).
호버 효과 제거: @media (hover: hover) 조건부 적용. 터치 디바이스에서 hover 상태가 고착되는 버그 방지.

04 — Components
컴포넌트별 모바일 대응 기준
네비게이션 바 (GNB)
필수
모바일
햄버거 메뉴 아이콘 (44×44px). 탭 시 풀스크린 오버레이 펼침. 로고 좌측, 햄버거 우측 배치.
태블릿+
상단 수평 메뉴로 전환. 로고 좌측, 메뉴 우측.
높이
모바일 56px / 데스크탑 64px. 상단 fixed, safe-area-inset 처리.
주의
iPhone 노치·Dynamic Island: env(safe-area-inset-top) 반드시 적용.
히어로 섹션
필수
높이
모바일 100svh (svh 미지원 시 100vh fallback). 배경 이미지 object-fit: cover.
텍스트
헤드라인 모바일 32px → 데스크탑 54px. 서브 15px → 18px. 배경 이미지 위 텍스트는 반드시 contrast 비율 4.5:1 이상.
CTA 버튼
모바일 width: 100% 또는 min-width: 200px. 높이 52px.
주의
배경 영상 자동재생: 모바일에서 muted playsinline autoplay 속성 필수. 데이터 절약 모드 고려 — 정지 이미지 폴백 제공.
카드 그리드 (선수모집·육성시스템 등)
필수
컬럼 수
모바일 1열 → 태블릿 2열 → 데스크탑 3열. grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)) 권장.
간격
모바일 gap: 12px → 데스크탑 gap: 24px.
카드 높이
고정 높이 금지. 콘텐츠 기반 자동 높이. 이미지는 aspect-ratio: 16/9 고정.
커리어 로드맵 인포그래픽
필수
모바일
좌우 병렬 → 세로 단일 컬럼 스택. 중앙 타임라인 축 유지, 카드는 아래로 쌓임. grid-template-columns: 1fr 56px 1fr → 56px 1fr 전환.
375px 이하
카드 폰트 1~2px 축소. 여백 16px로 줄임.
주의
Barlow 헤드라인 clamp() 적용 필수. 320px에서 overflow 발생하지 않을 것.
갤러리
중요
모바일
가로 스크롤 슬라이더 또는 2열 그리드. CSS scroll-snap 사용.
이미지
lazy loading 필수 (loading="lazy"). WebP 포맷 우선.
탭
카테고리 필터 버튼 가로 스크롤 가능하게. overflow-x: auto, 스크롤바 숨김.
선수모집 신청 폼
필수
입력 필드
높이 48px. 폰트 16px 이상 (iOS 자동 zoom 방지). autocomplete 속성 적절히 설정.
레이블
placeholder 대신 레이블 텍스트 필드 위에 항상 표시. 접근성 필수.
제출 버튼
width: 100%, 높이 52px. 제출 중 disabled 처리 + 로딩 인디케이터.
주의
키보드 올라올 때 레이아웃 밀림 확인. position: fixed 요소와 충돌 주의.
경기 일정 테이블
중요
모바일
테이블 → 카드 리스트로 전환. 각 경기를 개별 카드로. 날짜·팀·장소 세로 배치.
태블릿+
기본 테이블 레이아웃 복원.
가로스크롤
테이블 유지 시 overflow-x: auto 컨테이너 래핑. 스크롤 힌트(fade gradient) 우측에 표시.
푸터
일반
모바일
세로 단일 컬럼. 로고 → 메뉴 → 연락처 → 사업자 정보 → 저작권 순.
전화번호
<a href="tel:01041780207"> 래핑 필수. 탭 시 바로 전화 연결.
지도 링크
주소 탭 시 카카오맵 또는 네이버 지도 딥링크 연결.
05 — Images
이미지 최적화 전략
포맷 우선순위
  • WebP 우선, JPEG fallback
  • <picture> 태그로 포맷 분기
  • PNG는 투명도 필요 시만 사용
  • SVG는 로고·아이콘·인포그래픽
해상도 분기 (srcset)
  • 모바일: 600w (1x), 1200w (2x)
  • 태블릿: 1024w
  • 데스크탑: 1920w
  • 히어로 이미지 최대 200KB 이하
Lazy Loading
  • 히어로 이미지: loading="eager"
  • 나머지 전체: loading="lazy"
  • decoding="async" 병행 적용
  • width/height 속성 명시 (CLS 방지)
Alt 텍스트 규칙
  • 선수 사진: 이름 + 포지션
  • 경기 사진: 날짜 + 경기명
  • 장식용 이미지: alt=""
  • 한국어 alt 텍스트 작성
/* 반응형 이미지 예시 */
<picture>
  <source
    srcset="hero-600.webp 600w, hero-1200.webp 1200w, hero-1920.webp 1920w"
    sizes="(max-width: 767px) 100vw, (max-width: 1023px) 100vw, 100vw"
    type="image/webp">
  <img
    src="hero-1200.jpg"
    alt="서울금천축구클럽 훈련 현장"
    width="1920" height="1080"
    loading="eager"
    decoding="async">
</picture>
06 — Performance
모바일 퍼포먼스 기준값
90+
Lighthouse 모바일 점수
Performance 기준. 배포 전 반드시 측정.
2.5s
LCP 목표
Largest Contentful Paint. 3G 환경 기준.
0.1
CLS 목표
Cumulative Layout Shift. 이미지 width/height 명시로 방지.
100ms
INP 목표
Interaction to Next Paint. 탭 반응 기준.
Critical CSS 인라인: Above-the-fold 렌더링에 필요한 CSS는 <head> 내 <style>으로 인라인. 나머지는 비동기 로드.
JS 지연 로드: 분석·채팅 등 서드파티 스크립트는 defer 또는 페이지 로드 완료 후 주입.
Vercel 캐싱: 정적 에셋(이미지·폰트·CSS) Cache-Control max-age=31536000, immutable. Vercel 자동 처리 확인.
애니메이션 주의: CSS 애니메이션은 transform, opacity만 사용. top/left/margin 애니메이션은 reflow 발생 — 금지.
prefers-reduced-motion: 모든 애니메이션에 @media (prefers-reduced-motion: reduce) 대응 필수.
07 — CMS
CMS 관리자 모바일 규칙
경기 일정 등록: 모바일에서도 빠르게 등록 가능한 UI. 날짜 선택은 네이티브 <input type="date"> 사용 (모바일 UX 최적). 텍스트 입력 최소화.
갤러리 사진 업로드: 모바일 카메라 롤에서 직접 업로드 가능. accept="image/*" capture="environment" 지원. 업로드 시 자동 WebP 변환 또는 서버 사이드 최적화.
훈련 공지: 간단한 텍스트 에디터만 제공. 리치 텍스트 에디터는 모바일에서 조작 불편 — 최소한의 서식(굵기·줄바꿈)만 지원.
관리자 인증: 모바일 Safari / Chrome 기준 동작 확인. 세션 유지 시간 최소 24시간 (매 접속 시 로그인 불편 방지).
08 — Final Checklist
배포 전 모바일 체크리스트
실기기 테스트: iPhone SE (375px), 일반 Android (360px~390px) 실물 기기 확인. 시뮬레이터만으로 배포 금지.
320px 최소 너비: 모든 페이지에서 320px 기준 가로 스크롤 없이 동작 확인. Overflow 요소 없을 것.
Safe Area: iPhone 노치·Dynamic Island 영역 콘텐츠 겹침 없음. env(safe-area-inset-*) 전 페이지 적용.
폰트 크기 16px: <input>, <select>, <textarea>의 font-size 최소 16px. iOS 자동 zoom 방지.
터치 타겟 44px: 모든 인터랙티브 요소. Chrome DevTools Touch Simulator로 전 페이지 점검.
Lighthouse 90+: 모바일 모드 점수 확인. Performance·Accessibility·SEO 전항목.
전화·지도 링크: 푸터 전화번호 tel: 링크, 주소 지도 딥링크 실기기에서 동작 확인.
사업자등록번호 교체: 현재 123-12-12345 임시값. 실제 번호 확정 후 전체 파일 일괄 교체 후 배포.
