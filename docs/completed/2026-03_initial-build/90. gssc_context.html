05 — Decisions
주요 결정 사항
브랜드 컬러: 딥레드 #cc2222 (행동유도), 세피아 #c49550 (역사/정체성), 화이트 #f5f5f7. 레드와 세피아 같은 섹션 사용 금지.
폰트: 영문 헤드라인 Barlow Condensed 800, 한글 본문 Pretendard. 배경 #000 단일 유지.
포지셔닝: "축구 학원이 아니라 축구 매니지먼트 클럽". 초등~K4 수직 통합형 선수개발 모델.
타겟: 초등 학부모(Pain: 어디서 배워야 하나), 중등(Pain: 진학), 고등(Pain: 프로/대학), 성인(Pain: 마지막 기회).
SEO 방향: 비용 0원. 메타 태그 + Google Search Console + 네이버 서치어드바이저 + 네이버 블로그 운영.
자료 수집: 로고, 훈련사진, 진학현황, 코치 프로필, 훈련 스케줄, 파트너 목록 — 전부 확보 완료.
와이어프레임: 11개 페이지 전체 완료. 개발 지시서는 모든 와이어프레임 완성 후 한 번에 작성 예정.
CMS 필수: 경기일정·갤러리·훈련일정 클럽 대표가 직접 업데이트 가능한 관리자 구조 개발 단계에서 반드시 반영.
작업 방식: 직언 선호. 근거 있으면 입장 유지. 챕터 완료 시 컨텍스트 파일 업데이트.
