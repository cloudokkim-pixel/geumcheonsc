04 — Decisions
주요 결정 사항 (누적)
모바일 퍼스트 반응형: 모바일 접속 비중 높음. 모든 개발 산출물 모바일 기준 우선 설계. 카피 파일 각 섹션에 파란 박스로 모바일 주의사항 기재 완료.
훈련 장소: 서울특별시 관악구 조원로 56. SEO 문서의 "금천구" 키워드와 지역 불일치 — 추후 SEO 키워드 일부 조정 필요.
브랜드 컬러: 딥레드 #cc2222 (행동유도), 세피아 #c49550 (역사/정체성), 화이트 #f5f5f7. 레드와 세피아 같은 섹션 사용 금지.
폰트: 영문 헤드라인 Barlow Condensed 800, 한글 본문 Pretendard. 배경 #000 단일.
포지셔닝: "축구 학원이 아니라 축구 매니지먼트 클럽". 초등~K4 수직 통합형 선수개발 모델.
카피 톤: 히어로/헤드라인은 강하고 선언적, 본문/설명은 따뜻하고 공감 중심.
카피 파일 형태: 페이지별 파일 분리 (11개). 개발 지시서로 직행 가능한 구조.
CMS 필수: 경기일정·갤러리·훈련일정 클럽 대표가 직접 업데이트 가능한 관리자 구조.
SEO: 비용 0원. 메타 태그 + Google Search Console + 네이버 서치어드바이저 + 네이버 블로그.
작업 방식: 직언 선호. 근거 있으면 입장 유지. 챕터 완료 시 컨텍스트 파일 업데이트.
